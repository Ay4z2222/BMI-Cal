# BMI Calculator — เว็บคำนวณ BMI สารอาหาร และแคลอรี่ต่อวัน

เว็บแอปพลิเคชัน Static Web App (HTML5 / CSS3 / Vanilla JS) พัฒนาต่อยอดเพื่อความสวยงาม ทันสมัย ประสบการณ์ใช้งานระดับพรีเมียม (Modern Health-Tech UX/UI) รองรับทั้งอุปกรณ์มือถือ แท็บเล็ต และคอมพิวเตอร์ ทำงานบน GitHub Pages ได้ 100% โดยไม่มี build step หรือ dependency ภายนอก

---

## ✨ สิ่งที่ได้รับการพัฒนาและยกระดับ (Enhancements)

1. **ดีไซน์ระดับพรีเมียมสไตล์ Modern Health-Tech App**:
   - ปรับชุดสีและ Typography ด้วยฟอนต์ Google Fonts (`Prompt`, `Sarabun`, และ `Plus Jakarta Sans`)
   - ระบบ **Dark Mode / Light Mode** สลับได้ตามความชอบ และจดจำสถานะผ่าน `localStorage` (รวมถึงตรวจจับ system preferences)
   - แถบควบคุมเพศแบบ Interactive Segmented Buttons (👨 ชาย / 👩 หญิง)
   - การ์ดเลือกเป้าหมายแบบ Interactive Visual Cards (🔥 ลดน้ำหนัก / ⚖️ รักษาน้ำหนัก / 💪 เพิ่มกล้ามเนื้อ)

2. **การแสดงผล BMI แบบ Visual Meter**:
   - แถบสีแสดงสเกลตามเกณฑ์เอเชีย-แปซิฟิก พร้อมเข็มชี้ตำแหน่งแบบไดนามิก
   - ป้ายบอกสถานะและช่วงน้ำหนักที่เหมาะสม (Ideal Weight Range) พร้อมบอกส่วนต่างน้ำหนักจากเกณฑ์ปกติ

3. **ระบบความปลอดภัยทางโภชนาการ (Medical Safety Floor)**:
   - **รักษากฎความปลอดภัยอย่างเคร่งครัด**: แคลอรี่เป้าหมายจะไม่ต่ำกว่าขั้นต่ำปลอดภัย (1,500 kcal สำหรับเพศชาย และ 1,200 kcal สำหรับเพศหญิง)
   - มีการแจ้งเตือนพิเศษเมื่อเข้าเกณฑ์ความปลอดภัย เพื่อป้องกันผลกระทบต่อระบบเผาผลาญ

4. **การกระจายสารอาหารหลัก (Macronutrients) และเทียบแหล่งอาหาร**:
   - แถบสัดส่วนสารอาหารแบบ Segmented Progress Bar (โปรตีน / คาร์บ / ไขมัน)
   - การ์ดแสดงปริมาณกรัม แคลอรี่ และสัดส่วนเปอร์เซ็นต์
   - เทียบปริมาณโปรตีนเป็นมื้ออาหารจริง เช่น ไข่ไก่ (ฟอง), อกไก่สุก (กรัม), เต้าหู้ขาว (กรัม)
   - คำนวณปริมาณน้ำดื่มประจำวัน (33 มล./กก.) พร้อมเทียบเป็นจำนวนแก้ว

5. **ฟังก์ชันอำนวยความสะดวกเพิ่มเติม**:
   - ⚡ ปุ่มสุ่มตัวอย่างข้อมูล (Quick Demo) เพื่อทดสอบผลลัพธ์ได้ทันที
   - 📋 ปุ่มคัดลอกสรุปผลลัพธ์ (Copy Summary) นำไปวางในแชท โน้ต หรือส่งให้เทรนเนอร์ได้ทันที
   - 🖨️ ปุ่มพิมพ์หรือบันทึกเป็น PDF (Print-friendly CSS)
   - 🕒 ระบบบันทึกประวัติการคำนวณล่าสุด 5 รายการในเครื่อง (LocalStorage)

## 🔒 กฎเกณฑ์ทางการแพทย์และข้อสงวนสิทธิ์ (Preserved Compliance)

- **คงข้อความ Medical Disclaimer ครบถ้วน 100%**:
  - *"ใช้เกณฑ์เอเชีย-แปซิฟิก (ปกติ 18.5–22.9) BMI ไม่แยกกล้ามเนื้อกับไขมัน คนที่ออกกำลังกายหนักอาจได้ค่าสูงกว่าความเป็นจริง"*
  - *"ค่าทั้งหมดเป็นการประมาณเพื่อความรู้ทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ หากมีโรคประจำตัว ตั้งครรภ์ หรืออายุต่ำกว่า 18 ปี ควรปรึกษาแพทย์หรือนักกำหนดอาหาร"*
- **เกณฑ์ความปลอดภัยของพลังงาน (Calorie Floor)**: ป้องกันอันตรายจากการจำกัดแคลอรี่ที่รุนแรงเกินไป โดยล็อกค่าต่ำสุดไว้ที่ 1,500 kcal (ชาย) / 1,200 kcal (หญิง)

## 📐 สูตรและเกณฑ์คำนวณที่ใช้

| หมวดหมู่ | สูตร / เกณฑ์ |
| :--- | :--- |
| **BMI เกณฑ์เอเชีย-แปซิฟิก** | `< 18.5` น้ำหนักน้อย<br>`18.5 – 22.9` ปกติ (สมส่วน)<br>`23.0 – 24.9` น้ำหนักเกิน<br>`25.0 – 29.9` อ้วนระดับ 1<br>`≥ 30.0` อ้วนระดับ 2 |
| **ช่วงน้ำหนักปกติ** | $18.5 \times (\text{ส่วนสูงในหน่วยเมตร})^2$ ถึง $22.9 \times (\text{ส่วนสูงในหน่วยเมตร})^2$ |
| **BMR (Mifflin-St Jeor)** | ชาย: $10 \times W + 6.25 \times H - 5 \times Age + 5$<br>หญิง: $10 \times W + 6.25 \times H - 5 \times Age - 161$ |
| **TDEE** | $\text{BMR} \times \text{Activity Factor}$ (1.2 / 1.375 / 1.55 / 1.725) |
| **แคลอรี่เป้าหมาย** | ลดน้ำหนัก: $\text{TDEE} - 500$<br>เพิ่มกล้าม: $\text{TDEE} + 300$<br>รักษาน้ำหนัก: $\text{TDEE}$<br>*(จำกัดขั้นต่ำปลอดภัย: 1,500 kcal สำหรับชาย / 1,200 kcal สำหรับหญิง)* |
| **โปรตีน** | ลดน้ำหนัก: 1.6 ก./กก.<br>เพิ่มกล้าม: 1.8 ก./กก.<br>รักษาน้ำหนัก: 0.8 – 1.4 ก./กก. ตามกิจกรรม |
| **ไขมัน** | 25% ของพลังงานเป้าหมาย ($\div 9$ เพื่อแปลงเป็นกรัม) |
| **คาร์โบไฮเดรต** | พลังงานที่เหลือจากโปรตีนและไขมัน ($\div 4$ เพื่อแปลงเป็นกรัม) |
| **น้ำดื่ม** | $33 \text{ มล.} \times \text{น้ำหนักตัว (กก.)}$ |
