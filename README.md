# คำนวณ BMI แคลอรี่ และโปรตีนต่อวัน

เว็บหน้าเดียวสำหรับ GitHub Pages ใช้ HTML, CSS และ JavaScript ล้วน ไม่มี build step
เว็ปไซต์ https://ay4z2222.github.io/BMI-Cal/

กรอกเพศ อายุ ส่วนสูง น้ำหนัก ระดับกิจกรรม และเป้าหมาย แล้วดู BMI (เกณฑ์เอเชีย-แปซิฟิก), BMR, TDEE, แคลอรี่เป้าหมาย, โปรตีน คาร์บ ไขมัน และน้ำที่ควรดื่ม ผลทั้งหมดคำนวณในเบราว์เซอร์ ไม่ส่งข้อมูลไปที่ไหน

## ไฟล์
- `index.html` โครงหน้าและข้อความ
- `style.css` หน้าตา (ตามโหมดสว่าง/มืดของเครื่อง)
- `script.js` สูตรคำนวณ ประวัติ กราฟน้ำหนัก
- `og-image.png` รูปพรีวิวเวลาแชร์ลิงก์

## สูตร
- BMI: <18.5 น้อย, 18.5-22.9 ปกติ, 23-24.9 เกิน, 25-29.9 อ้วนระดับ 1, 30 ขึ้นไป อ้วนระดับ 2
- BMR: Mifflin-St Jeor
- TDEE: BMR คูณ 1.2 / 1.375 / 1.55 / 1.725 ตามระดับกิจกรรม
- เป้าหมาย: ลด -500, เพิ่ม +300 กิโลแคลอรี่ ไม่ต่ำกว่า 1,500 (ชาย) / 1,200 (หญิง)
- โปรตีน: ลด 1.6, เพิ่มกล้าม 1.8, คงน้ำหนัก 0.8-1.4 กรัมต่อกก. ตามกิจกรรม
- ไขมัน 25% ของพลังงาน ที่เหลือเป็นคาร์บ
- น้ำ 33 มล. ต่อกก.
